# Примеры tvision-rs как проекты TV Studio

Все 23 примера из [tvision-rs](https://github.com/cat386/tvision-rs/tree/main/examples),
каждый — отдельный проект TV Studio в своём каталоге. Открыть:

```
cargo run --release -- examples/tvdemo          # из каталога tvstudio
```

или **Файл → Открыть проект** → `examples/<имя>/<имя>.tvsp`. Дальше F9 —
собрать, Ctrl+F9 — запустить, **Проект → Строка меню / Строка состояния /
Команды** — править модель.

Проекты получены командой `tvs-import --examples ../tvision-rs examples`:
исходники скопированы, строка меню, строка состояния и константы команд
перенесены в модель (`<имя>.tvsp`), а в коде заменены на `ui::menu_bar()`,
`ui::status_line()` и `use ui::cmd::*`. Остальной код примеров не тронут,
их тесты проходят (`cargo test` в каталоге проекта).

Библиотека подключена путём `../../../tvision-rs` — tvision-rs должна
лежать рядом с tvstudio.

Все диалоги примеров — формы TV Studio (`forms/*.tvf`, 25 форм в 13
проектах): их можно открыть в дизайнере, проверить (Shift+F9) и
посмотреть сгенерированный код (F12).

* **Жирным** — формы, на которые уже переведён код: hello,
  learn_05_dialog и learn_06_form вызывают `forms::<имя>::build()`, так что
  правка формы мышью сразу меняет программу.
* Остальные формы извлечены из кода командой
  `tvs-import --forms examples/*/` (в среде — **Проект → Формы из кода**):
  координаты, надписи, пункты, связи меток, полосы прокрутки, циклы и
  простые замыкания вычислены по исходнику. Код этих примеров не менялся —
  он по-прежнему строит диалоги сам; форма — его точная копия для
  дизайнера. Чтобы перевести пример на форму, замените построение диалога
  вызовом `forms::<имя>::build()` (так сделано в трёх учебных примерах).
* Чего в форме нет: свои виджеты программ (дисплей калькулятора tvdemo,
  `ClickTester` в настройках мыши), узлы дерева и строки таблиц, которые
  программа строит из данных; заголовки и тексты, которые программа
  передаёт параметром, показаны как `{title}`, `{name}`; размер
  диалогов json_table и lfm/choose вычисляется во время работы — в форме
  образец 60×16.
